# motif-anchor-analysis

Investigates whether SNPs within CTCF motifs explain discrepancies between empirical (ChIP-seq) and predicted (AlphaGenome) allele-specific CTCF binding at loop anchors in GM12878 and HepG2 cell lines.

---

## File naming conventions

| Prefix | Meaning |
|--------|---------|
| `SCR_` | **Script** — runnable entry point, takes command-line arguments |
| `FUNC_` | **Function/utility** — helper module called by scripts, or a standalone one-off utility |

Output files are numbered by pipeline step (e.g. `1-`, `2-`, `3-`, `6-`, `7-`, `8-`).

---

## Pipeline overview

The full pipeline is driven by a single shell script:

```bash
bash SCR_motif-strength_vs_prediction.sh <output_folder_prefix>
```

Internally it runs the following steps in order:

```
SCR_motif-strength_vs_prediction.sh <prefix>
 ├── SCR_from-claud.py                        # step 1 – filter & label anchors
 ├── SCR_intersect_motifs_with_anchors.sh      # step 2 – bedtools intersect
 ├── SCR_analyze-snp-motif-anchors.py GM       # step 3 – SNP effect scoring (GM12878)
 ├── SCR_analyze-snp-motif-anchors.py HG2      # step 3 – SNP effect scoring (HepG2)
 ├── SCR_plot_examples.py                      # step 4 – summary plots
 ├── awk (inline)                              # step 5 – filter high-effect motifs
 ├── SCR_plot_ref_reads.py                     # step 5 – ref-allele read-bias plots
 └── ../prep_scripts/reorder-cols.py + sorting.py   # step 5 – column order & sort
```

## Scripts (`SCR_`)

### `SCR_motif-strength_vs_prediction.sh`

**Entry point — runs the full pipeline.**

```bash
bash SCR_motif-strength_vs_prediction.sh <output_folder_prefix>
```

| Positional arg | Description |
|---|---|
| `$1` | Output folder prefix. The actual folder name is auto-generated by appending threshold values (e.g. `prefix-c15-cd0-pb0.1-pg6.0-m8`) |

**Key parameters (hardcoded at top of script):**

| Variable | Default | Meaning |
|---|---|---|
| `motif_threshold` | `8` | Minimum `abs(delta_score)` for high-effect motif filter (step 5 awk) |
| `chip_diff_threshold` | `0` | Minimum `abs(DIFF_LOG2_data1)` to keep an anchor |
| `empirical_threshold` | `15` | Empirical either-homolog threshold for anchor selection |
| `bad_ag_threshold` | `0.1` | Maximum `abs(DIFF_LOG2_data2)` for a prediction to be classified as "bad" |
| `good_ag_threshold` | `6` | Maximum allowed difference between predicted and empirical log₂ for a prediction to be classified as "good" |
| `FULL` | `outside` | Prefix for input data files (selects `outside-CTCF-*.tsv` from altnas) |
| `Experiment` | `DRZ` | Experiment suffix filter applied to GM12878 data |

---

### `SCR_from-claud.py`

**Filters anchors by ChIP-seq threshold and labels each one** as `good`, `bad`, `cloud`, or `other` based on how well AlphaGenome predicts the empirical log₂ fold-change. All anchors passing the filter are kept (no sampling).

```bash
python SCR_from-claud.py <folder> <FULL> <chip_diff_threshold> <bad_ag_threshold> <good_ag_threshold> <experiment>
```

| Positional arg | Type | Description |
|---|---|---|
| `sys.argv[1]` | str | Output folder |
| `sys.argv[2]` | str | File prefix for altnas input files (`outside` or `full`) |
| `sys.argv[3]` | float | Minimum `abs(DIFF_LOG2_data1)` to retain an anchor (default `4.0`) |
| `sys.argv[4]` | float | `bad_ag_threshold` — max `abs(DIFF_LOG2_data2)` for a "bad" prediction (default `0.1`) |
| `sys.argv[5]` | float | `good_ag_threshold` — maximum allowed difference between predicted and empirical log₂ for a "good" prediction (default `1.0`) |
| `sys.argv[6]` | str | Experiment suffix to filter GM12878 rows (e.g. `DRZ`) |

**Prediction quality labels (priority order: good > cloud > bad > other):**

| Label | Condition |
|---|---|
| `good` | `abs(DIFF_LOG2_data1 − DIFF_LOG2_data2)` ≤ `good_ag_threshold` |
| `cloud` | Both empirical and predicted are > 0.5, or both < −0.5 |
| `bad` | `abs(DIFF_LOG2_data2)` < `bad_ag_threshold` |
| `other` | Does not meet any of the above |

**Reads (from `/mnt/altnas`):**
- `{FULL}-CTCF-HG2-15.tsv`
- `{FULL}-CTCF-GM12878-15.tsv`

**Outputs (written to `<folder>`):**

| File | Description |
|---|---|
| `1-motif_anchor_analysis_selected_anchors.tsv` | All anchors with prediction quality labels |
| `1-hepg2_selected_anchors_variants.bed` | Unique HepG2 anchor positions (BED) |
| `1-gm12878_selected_anchors_variants.bed` | Unique GM12878 anchor positions (BED) |
| `1-hepg2_filtered.tsv` | HepG2 anchors after ChIP-seq threshold filter |
| `1-gm12878_filtered.tsv` | GM12878 anchors after ChIP-seq threshold filter |
| `simple_quality_check.png` | Scatter of empirical vs predicted, colored by quality label |

### `SCR_intersect_motifs_with_anchors.sh`

**Intersects selected anchor BED files with CTCF motif variant files** using `bedtools intersect`.

```bash
bash SCR_intersect_motifs_with_anchors.sh <gm_bed> <hg2_bed> <output_folder>
```

| Positional arg | Description |
|---|---|
| `$1` | GM12878 anchor BED file |
| `$2` | HepG2 anchor BED file |
| `$3` | Output folder |

**Motif files used (hardcoded paths on GPFS):**
- GM12878: `FULL_LCL_ALPHAGENOME_RUNS_10.31.25/GM12878/combined/CTCF_MA0139.1.bed`
- HepG2: `HepG2/diploidGenomeOutput/combined/CTCF_MA0139.1.bed`

**Outputs:**

| File | Description |
|---|---|
| `2-GM_anchors_with_motifs.tsv` | Intersection result for GM12878 |
| `2-HG2_anchors_with_motifs.tsv` | Intersection result for HepG2 |

### `SCR_analyze-snp-motif-anchors.py`

**Classifies the effect of each SNP on its overlapping CTCF motif** and summarises per anchor.

```bash
python SCR_analyze-snp-motif-anchors.py <TYPE> <folder> <motif_threshold>
```

| Positional arg | Description |
|---|---|
| `sys.argv[1]` | Genome: `GM` or `HG2` |
| `sys.argv[2]` | Output folder |
| `sys.argv[3]` | Motif effect threshold (float) |

**Motif effect classification:**

| `motif_effect` value | Condition |
|---|---|
| `0` | `abs(delta_score)` < 1 — negligible |
| `1` | 1 ≤ `abs(delta_score)` < 5 — moderate |
| `2` | `abs(delta_score)` ≥ 5 — strong |

Per-anchor summary reports the **strongest** effect seen across all overlapping SNPs.

**Outputs:**

| File | Description |
|---|---|
| `3-{TYPE}_JUST-snp-analysis.tsv` | One row per anchor: `CHR, POS1, POS2, n_motif_snps, max_abs_delta, strongest_effect, anchor_summary` |
| `3-{TYPE}_snp_motif_details.tsv` | One row per anchor–SNP–motif combination with all scores |

### `SCR_plot_examples.py`

**Generates summary plots** comparing SNP motif effect to anchor prediction quality.

```bash
python SCR_plot_examples.py <folder> <chip_diff_threshold> <empirical_threshold> <motif_threshold> <bad_ag_threshold> <good_ag_threshold> <experiment>
```

Produces per-genome 5-panel figures and a combined cross-genome heatmap. Outputs saved to `<folder>/`.

---

### `SCR_plot_ref_reads.py`

**Generates reference-allele read-bias scatter plots** across five SNP category combinations (all, REF vs ALT only, ALT only, REF only, multi-SNP/phased). Produces two figures: one using a fixed ±1 band and one using the configurable `good_ag_threshold`.

```bash
python SCR_plot_ref_reads.py <folder> <good_ag_threshold>
```

| Positional arg | Description |
|---|---|
| `sys.argv[1]` | Folder containing `6-combined_anchor_snp_data.tsv` |
| `sys.argv[2]` | Maximum allowed difference between predicted and empirical log₂ for the "within ±thresh" figure (default `1.0`) |

**Outputs:**

| File | Description |
|---|---|
| `8-ref-comparison_within1.png` | Read-bias plots using fixed ±1 band |
| `8-ref-comparison_within{thresh}.png` | Read-bias plots using configurable threshold |

## Helper/utility files (`FUNC_`)

`FUNC_` files are reusable helpers or one-off utilities. They are **not** top-level pipeline entry points.

---

### `FUNC_filter-df.py`

**Generic in-place row filter** — keeps rows where a given field exceeds a threshold. Overwrites the input file.

```bash
python FUNC_filter-df.py <input_file> <field_name> <threshold>
```

| Positional arg | Description |
|---|---|
| `sys.argv[1]` | Path to TSV file (overwritten in place) |
| `sys.argv[2]` | Column name to filter on |
| `sys.argv[3]` | Numeric threshold (keeps rows where `field > threshold`) |

---

### `FUNC_make-file-with-details.py`

**Joins the two per-genome SNP motif detail files** with the selected anchor metadata into a single combined TSV.

```bash
python FUNC_make-file-with-details.py <hg2_details> <gm_details> <anchor_details> [output_file]
```

| Positional arg | Description |
|---|---|
| `sys.argv[1]` | `3-HG2_snp_motif_details.tsv` |
| `sys.argv[2]` | `3-GM_snp_motif_details.tsv` |
| `sys.argv[3]` | `1-motif_anchor_analysis_selected_anchors.tsv` |
| `sys.argv[4]` | Output path (default: `combined2.tsv`) |

---

### `FUNC_analyze-moods.py`

**Standalone diagnostic** — plots the distribution of `delta_score` and a boxplot of `delta_score` by `strongest_effect` for a given SNP detail file.

```bash
python FUNC_analyze-moods.py <snp_detail_tsv>
```

---

### `FUNC_get_variants.py`

**One-off utility** — extracts variant identifiers from `GM_anchors_with_motifs.tsv` and writes a flat variant table. Paths are **hardcoded** and must be edited before use.

**Output:** `GM_variants.tsv` — columns: `variant_id, CHROM, POS, REF, ALT`
